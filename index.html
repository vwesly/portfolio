lab/ai-security-gateway

Keep secrets out of the model

A policy engine that sits between developer tools and LLM providers. It screens every prompt for secrets, personal data and prompt injection, swaps sensitive values for reversible tokens, and sends high-risk prompts to a local Ollama model instead of the cloud. Edit the prompt and watch it decide.

  • LangGraph
  • RAG
  • pgvector
  • Ollama
  • Python
  • PostgreSQL

      lab/odoo-ai-analyst
      
        
      Ask your ERP anything
      
        
      An Odoo add-on I built that answers plain-language questions about CRM and sales data: rate customers by FY26 sales, find accounts about to churn, compare salesperson performance. The AI never sees your records. It receives the question and the data model, writes a query plan, and Odoo runs that plan under the user's own access rights. Answers come back as tables, bar and pie charts, ready to export to PDF or Excel. Switch the role and ask the same question.
      
        
      • Odoo add-on
      • Python ORM
      • OWL
      • LLM tool calling
      • Record rules
      • PDF · Excel export
      
        
      New: no application data shared with the AI · answers respect each user's role
